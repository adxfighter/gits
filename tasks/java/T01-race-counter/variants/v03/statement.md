# Резервирование товара на складе

Интернет-магазин резервирует товар в момент оформления заказа. Каждое оформление вызывает `StockItem.reserve(orderId, quantity)`: если товара достаточно, остаток уменьшается и возвращается резерв, иначе — пустой результат, и покупатель видит «Нет в наличии». При отмене заказа вызывается `release(reservation)`, и товар возвращается в остаток.

## Что наблюдается
Во время распродаж, когда один товар одновременно покупают сотни человек, магазин принимает **больше заказов, чем есть товара**. Складу приходится отменять часть оплаченных заказов. В отчётах иногда встречается отрицательный остаток. Вне распродаж проблема не воспроизводится.

## Что нужно сделать
Исправьте `StockItem` так, чтобы магазин не мог зарезервировать больше товара, чем есть на складе, при любом числе одновременных покупателей, а отмены резервов корректно возвращали товар.

## Ограничения
- Публичные методы и их сигнатуры менять нельзя.
- Класс `Reservation` доступен только для чтения.
- Проверки аргументов должны работать как раньше.

## Как будет проверено
Видимые тесты проверяют поведение в одном потоке. Скрытые тесты имитируют распродажу с одновременными покупками и отменами.
