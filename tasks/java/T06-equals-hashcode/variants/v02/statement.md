# Перенос записи к врачу

Регистратура поликлиники ведёт расписание приёма в `Schedule`: слот приёма (`AppointmentSlot`: врач и время) сопоставлен с записанным пациентом. Когда пациент просит перенести приём, регистратор вызывает `RescheduleService.reschedule(slot, newTime)`. Сервис возвращает слот, который теперь занят пациентом.

## Что наблюдается
После переноса запись «теряется»:
- поиск пациента по новому времени приёма ничего не находит;
- старое время по-прежнему считается занятым, но найти на нём пациента тоже нельзя;
- при этом общее число записей в расписании не меняется.

Врачи узнают о перенесённых пациентах, только когда те приходят на приём.

## Что нужно сделать
Исправьте перенос записи, чтобы после `reschedule` пациент находился по новому времени (в том числе по новому, созданному заново объекту слота), а старое время освобождалось.

## Ограничения
- `Schedule` доступен только для чтения.
- Конструктор `AppointmentSlot`, методы `doctorId()` и `time()`, а также сигнатура `reschedule` должны остаться прежними. Остальное в `AppointmentSlot` можно менять.
- Объект слота, переданный в `reschedule`, может храниться у вызывающего кода и не должен изменяться.
- Если новое время у врача уже занято, перенос по-прежнему отклоняется с `IllegalStateException`, а запись остаётся на старом времени.

## Как будет проверено
Видимые тесты проверяют запись на приём. Скрытые тесты проверяют переносы, в том числе цепочки переносов и попытки перенести на занятое время.
