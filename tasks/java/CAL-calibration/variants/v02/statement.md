# Разминка перед оценкой

Этот блок **не влияет на оценку**. Он нужен, чтобы вы освоились в редакторе, а платформа увидела ваш обычный темп работы. На блок отводится 5 минут; если не успеете, просто переходите к задачам.

## Часть 1. Перепечатайте фрагмент
В файле `Reference.java` находится фрагмент кода на Java. Перепечатайте его в файл `Typing.java` — между тройными кавычками, где сейчас пусто. Пожалуйста, набирайте текст вручную, не копируйте его: вставка из буфера обмена делает разминку бессмысленной.

Отступы и пробелы значения не имеют: тест сравнивает тексты без учёта пробельных символов и подсказывает место первого расхождения.

## Часть 2. Короткая задача
Реализуйте метод `StudentNames.format(raw)`, который приводит ФИО студента, набранное в любом регистре, к единому виду:
- каждое слово начинается с заглавной буквы, остальные буквы строчные;
- лишние пробелы в начале, в конце и между словами удаляются, слова разделяются одним пробелом;
- если имя пустое или состоит только из пробелов, метод бросает `IllegalArgumentException`.

Например, `иВАНОВА анна сергеевна` превращается в `Иванова Анна Сергеевна`.

## Как будет проверено
Только видимыми тестами: один проверяет перепечатанный фрагмент, три — метод из части 2. Скрытых тестов нет.
