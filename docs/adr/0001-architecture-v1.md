# ADR 0001. Архитектура локальной версии v1.0

**Статус:** принято. **Дата:** 2026-09-27.

## Контекст
Нужна демо-версия платформы для показа компаниям и получения писем о намерениях. Версия должна запускаться одной командой на ноутбуке (Windows 10/11 с Docker Desktop или Linux) без облака и внешних API. Команда — 3 человека, разработка с ИИ-ассистентом Claude Code.

## Решения
| Вопрос | Решение | Обоснование |
|---|---|---|
| Репозиторий | Монорепозиторий `gits` на GitHub | ИИ-ассистент видит весь контекст; одна команда запуска; один CI |
| База данных | PostgreSQL 17 | JSONB для телеметрии, очередь заданий на `SELECT … FOR UPDATE SKIP LOCKED`, Flyway |
| Redis | Не используется в v1.0 | Очередь запусков — в PostgreSQL, сессии — cookie на одном экземпляре API |
| Backend | Java 21, Spring Boot 3.5, Maven, модульный монолит | Соответствует заявке и компетенциям команды |
| Модули | `gits-core`, `gits-api`, `gits-runner`, `gits-taskbank` | Доступ к Docker-сокету — только у runner |
| Frontend | Angular 21, Monaco Editor из локальных ассетов, nginx | Демо работает без интернета |
| Песочница | Образ `gits-sandbox-java` (JDK 21, JUnit 5, AssertJ, Mockito); новый контейнер на каждый запуск | Изоляция: без сети, read-only, tmpfs, лимиты, таймаут |
| Изоляция ядра | runc по умолчанию; runsc (gVisor) через `SANDBOX_RUNTIME` на Linux | Docker Desktop для Windows не поддерживает gVisor штатно |
| Передача кода | tar-архив через stdin контейнера в tmpfs `/work` | Не нужны bind mount путей хоста |
| Фронт ↔ API | REST, опрос результата запуска; телеметрия пакетами по HTTP раз в 2 с | Проще и надёжнее WebSocket для демо |
| Аутентификация | Работодатель — email и пароль (BCrypt), сессионная cookie и CSRF; кандидат — одноразовая ссылка | Минимум сложности |
| LLM в runtime | Нет; интерфейс `LlmClient` и `StaticPoolTaskProvider`; банк задач сгенерирован заранее и провалидирован | Демо без ключей и внешних сервисов |
| Профиль | Java-разработчик, Java 21 core, 10 шаблонов × 5 вариантов | Spring-задачи — в v1.1 |
| Путь API | Все endpoint'ы под контекстом `/api` | Одинаковые пути напрямую и через nginx |

## Последствия
- Runner монтирует `/var/run/docker.sock` и работает от root внутри контейнера — допустимо для локальной демо-версии, недопустимо для облачной; в версии НИОКР runner переносится на выделенные ВМ с gVisor.
- Тесты, которым нужен Docker, помечаются `@Tag("docker")` и запускаются профилем `-Pdocker-tests` (в CI — всегда).
