# Топ продаваемых товаров

На главной странице магазина показывается блок «Хиты продаж». Его строит `TopSellers.top(sales, n)`: по списку продаж (`Sale`: артикул и число проданных единиц в одном заказе) нужно посчитать суммарные продажи каждого товара и вернуть `n` товаров с наибольшими продажами.

Правила блока:
- товары упорядочены по убыванию суммарного числа проданных единиц;
- при равных продажах товары упорядочены по артикулу по возрастанию;
- если товаров меньше `n`, возвращаются все.

## Что наблюдается
- Маркетологи жалуются, что в «Хитах продаж» показываются товары, которые почти не продаются.
- После акции часть популярных товаров вообще пропала из блока, хотя продаж у них не меньше, чем у показанных.

## Что нужно сделать
Исправьте `TopSellers.top` в соответствии с правилами блока.

## Ограничения
- `Sale` и `ProductSales` доступны только для чтения; сигнатура `top` не меняется.
- `n` всегда положительно.

## Как будет проверено
Видимые тесты проверяют подсчёт продаж и порядок на небольшом каталоге. Скрытые тесты проверяют товары с равными продажами, в том числе на границе `n`, пустые данные и каталог меньше `n`.
