# Сводка визитов пациентов

Для страховой компании клиника формирует сводку визитов за период: `VisitReport.summarize(visits, from, to)`. Визит (`Visit`) — это приход пациента в клинику в конкретный день. На одном визите пациента могут принять несколько врачей (консилиум, осмотр перед операцией) или ни одного (процедурный кабинет, приём медсестры).

По каждому пациенту, у которого были визиты в периоде, в сводке есть строка `PatientSummary`:
- число визитов;
- список **различных** врачей, принимавших пациента, по возрастанию идентификатора;
- число различных врачей.

Строки упорядочены по идентификатору пациента. Период задан датами `from` и `to` включительно; все показатели строки считаются только по визитам периода. Иногда в данных медицинской информационной системы (МИС) врач записан на один визит дважды — это по-прежнему один врач.

## Что наблюдается
- Страховая вернула счёт: у пациентов, которые ходили к одному врачу несколько раз, этот врач указан в списке врачей несколько раз.
- Визиты последнего дня месяца не попадают в сводку за месяц.
- У пациентов, которые давно наблюдаются в клинике, число различных врачей в сводке за месяц бывает больше, чем врачей, принимавших их в этом месяце.

## Что нужно сделать
Исправьте `VisitReport.summarize`, чтобы сводка соответствовала описанию.

## Ограничения
- `Visit` и `PatientSummary` доступны только для чтения; сигнатура `summarize` не меняется.

## Как будет проверено
Видимые тесты проверяют пациентов, каждого из которых принимали разные врачи. Скрытые тесты проверяют повторные визиты к одному врачу, дубликаты в данных, визиты без врачей, пациентов с визитами вне периода и границы периода.
