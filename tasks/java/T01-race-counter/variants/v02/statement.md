# Учёт трафика абонента

Сетевые шлюзы оператора связи передают данные о трафике абонента в сервис биллинга. Для каждого переданного пакета шлюз вызывает `TrafficMeter.addPacket(bytes)`. Шлюзов несколько, и вызовы приходят одновременно из разных потоков. Биллинг периодически запрашивает `snapshot()` — число пакетов и суммарный объём в байтах — и выставляет счёт по объёму.

## Что наблюдается
- Суммарный объём трафика в биллинге меньше, чем в журналах шлюзов, при этом разница непостоянна.
- Аналитики считают средний размер пакета как «байты / пакеты» по снимку и иногда получают невозможные значения: например, средний размер больше максимального размера пакета в сети.

## Что нужно сделать
Исправьте `TrafficMeter`, чтобы учёт был точным при одновременных вызовах, а каждый снимок показывал согласованные значения — объём и число пакетов из одного и того же момента.

## Ограничения
- Публичные методы и их сигнатуры менять нельзя.
- Класс `TrafficSnapshot` доступен только для чтения.
- Проверка размера пакета должна работать как раньше.

## Как будет проверено
Видимые тесты проверяют поведение в одном потоке. Скрытые тесты проверяют точность и согласованность учёта при одновременной работе нескольких шлюзов.
