# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.0.0] — 2026-09-28
Первая версия: локальная демо-версия платформы оценки практических навыков Java-разработчиков. Запуск — `scripts/up.ps1` или `scripts/up.sh`, всё работает в Docker Compose на одной машине.

### Кандидат
- Вход по одноразовой ссылке-приглашению, согласие на обработку данных, правила оценки.
- Сессия на 90 минут: разминка из двух частей (перепечатка образца и небольшая задача) и 3 задачи из разных шаблонов под уровень приглашения.
- Редактор Monaco (ассеты локально, без внешних запросов), автосохранение, «Запустить» на видимых тестах (до 60 запусков на задачу), «Отправить решение» на скрытые тесты.
- Сбор телеметрии ввода только после согласия и только на странице оценки: категории клавиш без символов, правки, вставки с источником, фокус, видимость вкладки.

### Работодатель
- Приглашения, их отзыв, список с баллом и уровнем доверия.
- Отчёт по сессии: предварительный балл, по задачам — исправленные скрытые тесты и проверки «ничего не сломано», время, запуски, индикаторы достоверности с пояснениями, сработавшие правила с подсветкой индикаторов, итоговый код.
- Воспроизведение сессии: код по шкале времени, вставки, запуски, график скорости набора, проверка совпадения с итоговым кодом.

### Администратор
- Банк задач с отчётами валидации и всеми файлами вариантов, все сессии, пересчёт балла.
- Выгрузка для исследования (ZIP с JSONL) со случайными псевдонимами на каждый архив; выгрузка сессии как демо-файла.

### Исполнение кода
- Песочница `gits-sandbox-java` (JDK 21, JUnit 5, AssertJ, Mockito): без сети, файловая система только для чтения, лимиты памяти, CPU, процессов и времени, непривилегированный пользователь; самопроверка «злыми» программами в CI.
- Сервис runner с очередью в PostgreSQL (`RUNNER_CONCURRENCY` параллельных запусков); скрытые тесты в результатах — без имён.

### Банк задач
- 10 шаблонов (T01–T10: гонки, взаимные блокировки, утечки, legacy-рефакторинг, equals/hashCode, Stream API, CompletableFuture, ограничитель частоты, производитель-потребитель) по 5 вариантов и калибровочная разминка; каталог — `tasks/java/CATALOG.md`.
- Валидатор (v2): схема, запрещённые конструкции, утечки решения в видимые тесты, эталон проходит все тесты 20 раз из 20, заготовка проваливает скрытые, время эталона; списки проверок «ничего не сломано».

### Оценка
- Предварительный балл: доля исправленных скрытых тестов (тесты, которые заготовка проваливает) с весами junior 1, middle 1,5, senior 2; сломанная проверка «ничего не сломано» или неизменённый код — 0; разминка — с весом 0,5 ([ADR 0015](docs/adr/0015-score-fixed-tests-and-warm-up.md)).
- Индикаторы достоверности по правилам ([docs/indicators.md](docs/indicators.md)): доля вставок и внешние вставки, наибольшая вставка, всплески набора (в том числе относительно разминки), паузы перед всплесками, уход с вкладки, линейность набора, доля правок, время до первого запуска и число запусков; уровни «Замечаний нет», «Есть замечания», «Серьёзные замечания».

### Демо и проверки
- Три записанные демо-сессии (честное решение, крупные вставки, перепечатывание со второго экрана), `scripts/demo-reset.*`, `demo-seed`.
- CI: backend (unit и интеграционные тесты с Testcontainers), frontend, самопроверка песочницы, повторная валидация изменённых вариантов, сборка образов и smoke-тесты, E2E на Playwright с запуском через `scripts/up.sh`.
- Нагрузочная проверка: 10 одновременных кандидатов, `RUNNER_CONCURRENCY=4` — p95 ответа на запуск 7,6 с ([docs/performance.md](docs/performance.md)).
- Чек-лист безопасности — [docs/security-checklist.md](docs/security-checklist.md).

### Известные ограничения
Локальная версия без HTTPS и отправки писем, правиловые индикаторы вместо моделей, предварительный балл до психометрической калибровки, один профиль (Java-разработчик) — подробнее в [README](README.md#известные-ограничения-v10).
