# Тарифы перевозчиков

При оформлении отправки логистический сервис показывает тарифы нескольких перевозчиков. `RateShopping.quotes(weightGrams)` асинхронно запрашивает у каждого перевозчика (`CarrierClient.rate`) тариф на посылку заданного веса и возвращает `CompletableFuture<List<CarrierRate>>`: тарифы ответивших перевозчиков по возрастанию цены (при равной цене — по имени перевозчика).

Сервис получает общий пул потоков `Executor`, на котором работают и другие задачи приложения. Пул небольшой.

## Что наблюдается
- Если хотя бы один перевозчик отвечает ошибкой, клиент не видит ни одного тарифа.
- Под нагрузкой приложение «замирает»: потоки пула заняты ожиданием ответов перевозчиков, а другие задачи, поставленные в тот же пул, не выполняются, пока перевозчики не ответят.

## Что нужно сделать
Исправьте `RateShopping.quotes`:
- тарифы ответивших перевозчиков возвращаются, даже если часть перевозчиков ответила ошибкой; если ошиблись все — пустой список;
- ожидание ответов не занимает потоки пула.

## Ограничения
- `CarrierClient` и `CarrierRate` доступны только для чтения; конструктор и сигнатура `quotes` не меняются.
- Результат формируется, когда ответили или отказали все перевозчики.

## Как будет проверено
Тесты используют перевозчиков-заглушки, ответы которых тест завершает вручную, и пул из одного потока. Видимые тесты проверяют успешные ответы. Скрытые тесты проверяют ошибки перевозчиков, доступность пула во время ожидания и порядок тарифов.
