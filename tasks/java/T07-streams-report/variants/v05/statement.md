# Статистика суточного потребления

Энергосбытовая компания показывает клиентам статистику по их счётчикам: `ConsumptionStats.build(meterIds, readings)`. Счётчик передаёт показания (`Reading`) несколько раз в сутки: каждое показание — это чистое потребление в Вт·ч за интервал. У клиентов с солнечными панелями значение может быть отрицательным: днём дом отдаёт энергию в сеть.

По каждому счётчику из списка (в порядке возрастания идентификатора) в отчёте есть строка `MeterStats`:
- общее потребление за все дни;
- число дней, за которые есть показания;
- минимальное и максимальное **суточное** потребление (сумма показаний за сутки);
- среднее суточное потребление.

Если у счётчика нет ни одного показания (например, его только что установили), общее потребление и число дней равны нулю, а минимум, максимум и среднее пустые.

## Что наблюдается
- У обычных клиентов минимальное суточное потребление всегда показывается как 0 Вт·ч.
- У владельцев солнечных панелей, которые всё время отдают энергию в сеть, максимум тоже равен 0.
- Минимум и максимум не совпадают с суммами по дням в детализации.
- Для новых счётчиков в приложении отображается «NaN».

## Что нужно сделать
Исправьте `ConsumptionStats.build`, чтобы статистика соответствовала описанию.

## Ограничения
- `Reading` и `MeterStats` доступны только для чтения; сигнатура `build` не меняется.
- Показания счётчиков, которых нет в списке, игнорируются.

## Как будет проверено
Видимые тесты проверяют счётчики с одним показанием в сутки и дни как с потреблением, так и с отдачей. Скрытые тесты проверяют несколько показаний в сутки, только положительные или только отрицательные сутки и счётчики без показаний.
