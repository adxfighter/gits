# Зависание переводов между счетами

Сервис переводов банка выполняет переводы между счетами клиентов из нескольких потоков. По правилам банка любое изменение счёта выполняется под блокировкой этого счёта (монитор объекта `Account`), поэтому `TransferService.transfer(from, to, amount)` блокирует оба счёта и переносит сумму.

## Что наблюдается
Под нагрузкой обработка переводов периодически полностью останавливается: потоки не завершаются, новые переводы не обрабатываются, загрузка процессора при этом нулевая. Помогает только перезапуск сервиса. Инцидент чаще всего случается, когда два клиента одновременно переводят деньги друг другу.

## Что нужно сделать
Устраните причину зависания в `TransferService`. Перевод должен оставаться атомарным: деньги не должны появляться, исчезать или списываться без зачисления, а переводы между разными парами счетов не должны ждать друг друга без необходимости.

## Ограничения
- Публичные методы и их сигнатуры менять нельзя.
- Класс `Account` доступен только для чтения; правило «изменение счёта — под монитором счёта» сохраняется.
- Проверки аргументов и недостатка средств должны работать как раньше.

## Как будет проверено
Видимые тесты проверяют переводы в одном потоке. Скрытые тесты выполняют встречные переводы из нескольких потоков с ограничением времени.
