# Кэш маршрутов доставки

Сервис планирования доставки строит маршрут между городами с помощью `RoutePlanner`. Построение маршрута — тяжёлая операция, поэтому результаты кэшируются в `RouteCache`. Дорожная ситуация меняется (ремонты, перекрытия), поэтому каждый маршрут действует ограниченное время — `ttl`, после чего его нужно построить заново. Кэш также ограничен по размеру: при переполнении вытесняется маршрут, который дольше всех не запрашивали.

## Что наблюдается
- Водители получают маршруты через перекрытые участки дорог, хотя перекрытие появилось в планировщике несколько часов назад. Для популярных направлений маршрут не обновляется, пока его постоянно запрашивают.
- Метрика `size()` показывает, что кэш почти всегда заполнен, но значительная часть записей давно просрочена.

## Что нужно сделать
Исправьте `RouteCache`: маршрут, срок жизни которого истёк, не должен возвращаться — его нужно построить заново. Просроченные маршруты не должны занимать место в кэше и учитываться в `size()`. Маршрут действителен, пока текущее время строго меньше момента истечения.

## Ограничения
- Публичные методы и их сигнатуры менять нельзя.
- `Route` и `RoutePlanner` доступны только для чтения.
- Текущее время берётся только из переданных в конструктор часов `Clock`.
- Кэш используется из одного потока; ограничение ёмкости должно сохраниться.

## Как будет проверено
Видимые тесты проверяют кэширование маршрутов. Скрытые тесты управляют часами и проверяют истечение срока жизни, размер кэша и вытеснение.
