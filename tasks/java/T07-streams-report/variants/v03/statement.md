# Помесячная выписка по счёту

Клиент интернет-банка может запросить помесячную выписку за период: `MonthlyStatement.build(operations, from, to)`. По каждому месяцу периода с `from` по `to` включительно в выписке есть строка `MonthLine`:
- число операций за месяц;
- оборот — сумма модулей всех операций (зачислений и списаний);
- крупнейшее списание — наибольшая сумма списания (по модулю) или пустое значение, если списаний не было.

Период может быть любым, в том числе длиннее года. Строки идут в хронологическом порядке. Строка есть у каждого месяца периода, даже если операций в нём не было.

## Что наблюдается
- Выписка за период «ноябрь 2025 — февраль 2026» приходит с месяцами в порядке январь, февраль, ноябрь, декабрь.
- Для клиентов, у которых в каком-то месяце не было операций или были только зачисления (например, в отпуске, когда приходила только зарплата), выписка не формируется: сервис отвечает ошибкой 500.

## Что нужно сделать
Исправьте `MonthlyStatement.build`, чтобы выписка соответствовала описанию.

## Ограничения
- `Operation` и `MonthLine` доступны только для чтения; сигнатура `build` не меняется.
- Операции вне периода в выписку не попадают. `from` не позже `to`.

## Как будет проверено
Видимые тесты строят выписку внутри одного года по месяцам со списаниями. Скрытые тесты проверяют переход через год, периоды длиннее года, пустые месяцы, месяцы только с зачислениями и границы периода.
