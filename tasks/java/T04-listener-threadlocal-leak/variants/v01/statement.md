# Подписки на события курса

Платформа онлайн-курсов рассылает события курса (новый урок, изменение расписания, публикация оценок) через `CourseEventBus`. Каждая открытая страница курса в браузере слушателя создаёт подписку `subscribe(listener)`, а при закрытии страницы вызывается `close()` у полученной подписки.

## Что наблюдается
Сервер уведомлений стабильно расходует всё больше памяти и раз в несколько дней перезапускается. Метрика `listenerCount()` показывает сотни тысяч слушателей, хотя одновременно онлайн не больше пары тысяч человек. При этом закрытые страницы уведомления действительно не получают.

## Что нужно сделать
Исправьте `CourseEventBus`, чтобы закрытие подписки освобождало слушателя: закрытые подписки не должны учитываться в `listenerCount()` и удерживаться шиной в памяти.

## Ограничения
- Публичные методы и их сигнатуры менять нельзя.
- Класс `CourseEvent` доступен только для чтения.
- Закрытые подписки по-прежнему не получают события; повторное закрытие подписки не должно приводить к ошибке.
- Шина используется из одного потока.

## Как будет проверено
Видимые тесты проверяют доставку событий. Скрытые тесты проверяют число слушателей после массового открытия и закрытия подписок и доставку событий оставшимся подписчикам.
