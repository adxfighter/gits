# Сводка визитов пациентов

Для страховой компании клиника формирует сводку визитов за период: `VisitReport.summarize(visits, from, to)`. Визит (`Visit`) — это приход пациента в клинику в конкретный день. На одном визите пациента могут принять несколько врачей (консилиум, осмотр перед операцией) или ни одного (процедурный кабинет, приём медсестры).

По каждому пациенту, у которого были визиты в периоде, в сводке есть строка `PatientSummary`:
- число визитов;
- список **различных** врачей, принимавших пациента, по возрастанию идентификатора;
- число различных врачей.

Строки упорядочены по идентификатору пациента. Период задан датами `from` и `to` включительно.

## Что наблюдается
- Страховая вернула счёт: у пациентов, которые ходили к одному врачу несколько раз, этот врач указан в сводке несколько раз, а число врачей завышено.
- Визиты последнего дня месяца не попадают в сводку за месяц.
- Иногда в данных МИС врач записан на визит дважды; в сводке он тоже учитывается дважды.

## Что нужно сделать
Исправьте `VisitReport.summarize`, чтобы сводка соответствовала описанию.

## Ограничения
- `Visit` и `PatientSummary` доступны только для чтения; сигнатура `summarize` не меняется.

## Как будет проверено
Видимые тесты проверяют пациентов, каждого из которых принимали разные врачи. Скрытые тесты проверяют повторные визиты к одному врачу, дубликаты в данных, визиты без врачей и границы периода.
