# Отчёт о среднем балле по курсам

Учебный отдел в конце семестра строит отчёт `CourseReport.build(courses, grades)`. В отчёте одна строка (`CourseLine`) на каждый курс из списка, строки упорядочены по коду курса. В строке указаны код и название курса, число выставленных оценок и средний балл.

Курс определяется **кодом**. Названия могут повторяться: например, «Математический анализ» читается двум потокам под кодами `MA-101` и `MA-102`.

## Что наблюдается
- В отчёте весеннего семестра у двух потоков матанализа оказался одинаковый средний балл и одинаковое число оценок, хотя преподаватели ставили разные оценки.
- Если по курсу ещё не выставлено ни одной оценки (например, практика, где оценки ставят позже), построение отчёта падает с исключением, и отчёт не формируется вообще.

## Что нужно сделать
Исправьте `CourseReport`:
- средний балл и число оценок считаются отдельно для каждого курса;
- курс без оценок попадает в отчёт с нулём оценок и пустым средним (`OptionalDouble.empty()`).

## Ограничения
- `Course`, `Grade`, `CourseLine` доступны только для чтения.
- Оценки по курсам, которых нет в списке `courses`, в отчёт не попадают.

## Как будет проверено
Видимые тесты строят отчёт по курсам с разными названиями. Скрытые тесты проверяют курсы с одинаковыми названиями, курсы без оценок, пустые данные и порядок строк.
