# ADR 0010. Проверка источника вставки в задачах

**Статус:** принято. **Дата:** 2026-09-28. **Этап:** доработка по ручному тестированию (PR #29).

## Контекст
Вставка кода — нормальная часть работы: кандидат переносит свой код между местами и файлами, копирует имена из условия. Подозрительна только вставка текста из других источников: с сайта, из другой программы, от ИИ-ассистента. Владелец продукта решил: кандидат сразу видит предупреждение; свой код (даже набранный и затем вырезанный), текст условия и вывод запусков копировать можно; проверка не должна тормозить редактор.

## Решения
| Вопрос | Решение | Обоснование |
|---|---|---|
| Где проверять | В браузере, в момент вставки | Только там в этот момент известен текущий текст всех файлов; сервер видит лишь итог |
| Что своё | Вставленный текст без пробельных символов ищется как подстрока в текущем тексте файлов задачи (редактируемых, readonly и тестов), в условии в том виде, как его видит кандидат, в выводе последнего запуска и в последних 20 фрагментах, скопированных или вырезанных в редакторе | Перенос своего кода, текст условия и вывод тестов не вызывают подозрения |
| Производительность | Без индексов и кешей: поиск только в момент вставки по нескольким килобайтам текста, доли миллисекунды | Вставка — редкое событие; на обычный набор ничего не тратится |
| Порог | 10 непробельных символов, одинаково в браузере и на сервере | Короткие вставки (имя переменной) не шумят |
| Вставка без события paste | Одно изменение от 10 символов (перетаскивание, расширение браузера) проверяется так же; принятая подсказка автодополнения — нет | Нельзя обойти проверку перетаскиванием |
| Результат | Предупреждение кандидату; флаг `ownCode` в телеметрии; индикатор `externalPastes` и правило YELLOW | Прозрачно для кандидата, видно работодателю |
| Разминка | Часть 2 проверяется так же; часть 1 — по правилам ADR 0009 | В перепечатке своего кода нет |

## Последствия
- Решение о том, своё ли это, принимает клиент, и его можно подделать, как и всю телеметрию (ADR 0007). Для v1.0 это приемлемо: индикатор — подсказка, а не доказательство.
- При проверке нашлась ошибка P11: слушатели paste, copy и cut не подключались (`getDomNode()` у Monaco равен `null`, пока нет модели), и копирование не записывалось. Слушатели перенесены на `getContainerDomNode()`.
- Документация Java — такой же «другой источник»: её можно читать, но не копировать. Так прямо сказано в правилах оценки (решение владельца продукта); список разрешённых источников для вставки не ведётся.
