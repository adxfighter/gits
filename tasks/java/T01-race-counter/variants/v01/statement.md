# Счётчик обработанных платежей

Процессинговый центр банка принимает платежи в несколько потоков. После обработки каждого платежа поток вызывает `PaymentStatistics.record(payment)`, а мониторинг раз в минуту читает `processedCount()` и сверяет его с числом платежей в журнале операций.

## Что наблюдается
На тестовом стенде при одном потоке обработки показатели совпадают. В промышленной среде, где платежи обрабатывают четыре потока, счётчик мониторинга стабильно показывает **меньше** платежей, чем записано в журнале, и расхождение растёт с нагрузкой. Некорректные платежи (с нулевой или отрицательной суммой) при этом отклоняются правильно.

## Что нужно сделать
Исправьте `PaymentStatistics` так, чтобы счётчик был точным при любом числе потоков, вызывающих `record` одновременно.

## Ограничения
- Публичные методы и их сигнатуры менять нельзя.
- Класс `Payment` доступен только для чтения.
- Отклонение некорректных платежей должно работать как раньше.

## Как будет проверено
Видимые тесты проверяют поведение в одном потоке. Скрытые тесты дополнительно проверяют точность счётчика при одновременной работе нескольких потоков.
