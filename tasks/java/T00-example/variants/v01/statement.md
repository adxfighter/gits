# Статистика успеваемости

Кафедра использует небольшой сервис `GradeStatistics`, который по оценкам студентов за экзамен считает средний балл, лучший результат и число студентов, сдавших экзамен. Экзамен считается сданным, если студент набрал **не меньше** проходного балла.

После начала сессии преподаватели заметили расхождение: в отчётах сервиса студентов, сдавших экзамен, оказывается меньше, чем в ведомостях, которые кафедра заполняет вручную. Остальные показатели отчёта совпадают.

## Что нужно сделать
Найдите причину расхождения и исправьте её в классе `GradeStatistics`.

## Ограничения
- Публичные методы и их сигнатуры менять нельзя: сервис используют другие системы кафедры.
- Класс `Grade` доступен только для чтения.
- Не меняйте поведение методов, которые работают правильно.

## Как будет проверено
Видимые тесты можно запускать сколько угодно раз — они проверяют базовое поведение. После отправки решение проверяется набором скрытых тестов.
