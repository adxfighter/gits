# Кэш курсов валют

Сервис конвертации валют в мобильном банке получает курсы из внешнего поставщика (`RateProvider`). Каждый запрос к поставщику платный, поэтому курсы кэшируются в `ExchangeRateCache`. Кэш ограничен по размеру: когда он заполнен, одна запись вытесняется. Кэш также считает попадания и промахи — по этой статистике финансовый отдел контролирует расходы на поставщика.

## Что наблюдается
После запуска конвертации для экзотических валют расходы на поставщика курсов выросли в несколько раз. Статистика показывает много промахов для самых популярных пар — USD/RUB и EUR/RUB, — хотя к ним обращаются постоянно и они должны почти всегда находиться в кэше. Каждый клиент, открывший курс редкой валюты, «выталкивает» популярную пару.

## Что нужно сделать
Исправьте `ExchangeRateCache`, чтобы при переполнении вытеснялся курс, к которому **дольше всех не обращались**, а часто запрашиваемые пары оставались в кэше.

## Ограничения
- Публичные методы и их сигнатуры менять нельзя.
- `CurrencyPair` и `RateProvider` доступны только для чтения.
- Кэш используется из одного потока; статистика и остальные методы должны работать как раньше.

## Как будет проверено
Видимые тесты проверяют кэширование и конвертацию. Скрытые тесты проверяют, какие курсы остаются в кэше при смешанной нагрузке, и точность статистики.
