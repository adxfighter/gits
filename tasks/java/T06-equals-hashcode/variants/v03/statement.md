# Корзина не находит товар

Корзина интернет-магазина (`Cart`) хранит количество товара по артикулу (`Sku`). Артикул нормализуется при создании: пробелы по краям отбрасываются, буквы приводятся к верхнему регистру, так что `" ab-100 "` и `"AB-100"` — один и тот же товар.

## Что наблюдается
- В разработке и в модульных тестах с артикулами-константами всё работает.
- В продакшене артикулы приходят из JSON-запросов и сканера штрихкодов. Повторное добавление товара создаёт в корзине вторую строку вместо увеличения количества, а удаление товара «не срабатывает».

## Что нужно сделать
Исправьте `Sku`, чтобы артикулы с одинаковым нормализованным значением были равны, откуда бы ни пришла строка.

## Ограничения
- `Cart` доступен только для чтения.
- Конструктор `Sku(String)` и метод `code()` должны остаться прежними, как и правила нормализации.

## Как будет проверено
Видимые тесты работают с артикулами-константами. Скрытые тесты используют строки, полученные во время выполнения: из разбора текста, конкатенации и `StringBuilder`.
