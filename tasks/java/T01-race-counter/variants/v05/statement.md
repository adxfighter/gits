# Статистика посещения онлайн-занятий

Платформа онлайн-обучения фиксирует, сколько минут каждый слушатель провёл на занятии. Серверы видеоконференций присылают данные параллельно: по одному посещению через `AttendanceStatistics.record(minutes)` или пачкой через `recordAll(list)` после окончания занятия. Методисты смотрят `summary()` — число посещений, суммарное и максимальное время — и строят по нему отчёты о вовлечённости.

## Что наблюдается
Предыдущий разработчик уже пытался устранить потерю данных, но проблемы остались:
- после крупных занятий число посещений в отчёте меньше, чем слушателей в журнале конференции;
- иногда отчёт показывает среднее время больше максимального, чего быть не может.

## Что нужно сделать
Доведите исправление до конца: учёт должен быть точным при одновременных вызовах `record` и `recordAll`, а `summary()` — всегда показывать согласованное состояние, в котором число посещений, сумма и максимум относятся к одному моменту.

## Ограничения
- Публичные методы и их сигнатуры менять нельзя.
- Класс `AttendanceSummary` доступен только для чтения.
- Проверки аргументов должны работать как раньше.

## Как будет проверено
Видимые тесты проверяют поведение в одном потоке. Скрытые тесты проверяют точность и согласованность статистики при одновременной записи и чтении.
